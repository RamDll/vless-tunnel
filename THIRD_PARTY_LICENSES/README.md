# Лицензии сторонних компонентов

`.deb`-пакет зашивает готовый бинарник **Xray-core** (https://github.com/XTLS/Xray-core),
распространяемый под **Mozilla Public License 2.0**. Скрипт не изменяет его исходный код
и использует ядро как есть, скачивая официальный релиз с GitHub.

Полный текст лицензии: [`Xray-core-MPL-2.0.txt`](./Xray-core-MPL-2.0.txt).

Собственный код проекта (`vless-tunnel.sh`, `gui/`, `packaging/`) распространяется
под лицензией MIT — см. [`LICENSE`](../LICENSE) в корне репозитория.
